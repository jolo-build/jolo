# Roadmap

Where Jolo is heading. This is a living document — priorities shift with feedback, and dates are deliberately absent. Items listed here are intentions, not commitments.

## Near term

- **Easier installs.** Homebrew tap and an npm package for the CLI, alongside the existing installer script and DMG.
- **Signed, auto-updating desktop.** Apple Developer ID signing and notarization, then silent updates through the existing release-check plumbing.
- **More platforms.** Windows and Linux builds of the desktop app — the CLI already ships for Linux.
- **Shareable tasks.** Publish a task or synced chat as a read-only link through Jolo Access.
- **`jolo demo`.** A scripted first-run session so a new install shows what Jolo does before any agent is configured.

## Mid term

- **Richer orchestration.** Parallel plan tasks, dependencies between steps, and better retry controls.
- **Deeper agent coverage.** More installed-agent integrations and finer per-task model control.
- **Access teams.** Shared workspaces, comments, and hand-offs between people and agents.

## Longer term

- **Mobile and web review.** Follow and approve work away from the desktop.
- **A public task ecosystem.** Templates and example plans that new workspaces can start from.

## How to influence this

- Open a [feature request](https://github.com/jolo-build/jolo/issues/new?template=feature_request.md).
- Discuss in [GitHub Discussions](https://github.com/jolo-build/jolo/discussions).
- See what shipped recently in [CHANGELOG.md](CHANGELOG.md).
