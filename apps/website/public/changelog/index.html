Changelog

What changed in each release. Full history lives in CHANGELOG.md.

0.2.5 — 2026-09-14

  • Terminal themes in the CLI: a /themes picker, jolo theme commands, and live-reloading custom JSON themes.
  • Slash-command suggestions: type / to browse, filter, and complete composer commands.
  • Desktop side-panel tabs stay per workspace; file-link previews, a browser activity cursor, and clearer file errors.
  • Markdown tables and richer file-reference links in chat.
  • Model harness fixes: resume after an in-run compaction, checkpoint ordering, per-attempt iteration budget, provider stream bounds.

0.2.4 — 2026-09-13

  • Closing the last panel tab now closes the panel, including with the keyboard shortcut.
  • Task and folder attention now follows the current prompt instead of superseded paused or failed runs.
  • Fixed the README terminal animation and added matching light and dark themes with reduced-motion support.
  • Enabled automatic npm publishing through GitHub Actions and scheduled Homebrew release updates.

0.2.3 — 2026-09-13

  • Windows and Linux desktop release builds, npm CLI distribution, and Homebrew tap automation.
  • Shareable Access chats and improved chat synchronization.
  • Fixed CLI cursor and word navigation, Devin cancellation, and task-specific change summaries.
  • Improved file links, previews, panel tabs, keyboard shortcuts, and stopped-task icons.
  • CLI demo, website comparison pages, and release history.

0.2.1 — 2026-09-13

  • Redesigned Access chats and improved mobile website layouts.
  • Desktop previews and workflow fixes.

0.2.0 — 2026-09-12

  • Changes cards tied to completed replies, so finished work is easy to inspect.
  • Devin CLI integration.
  • Account chat sync and polished account and task interfaces.
  • Clearer reasoning-effort labels; fixed visualization rendering for Devin replies.

0.1.4 — 2026-09-12

  • Fixed agent discovery for agents installed outside a login shell.
  • Website release downloads refresh automatically.

0.1.3 — 2026-09-12

  • Fixed file links and visualization controls.
  • Redesigned the Access task editor with Markdown; added a desktop task rail.
  • Chat file attachments; ACP model effort discovery fixes; improved CLI themes.

0.1.2 — 2026-09-12

  • Refined desktop controls; task numbers are now scoped to workspaces.
  • Public guide with animated walkthroughs at docs.jolo.build.
  • Orchestrator plans and desktop examples on the website.

0.1.1 — 2026-09-11

  • macOS DMGs built and published in GitHub Actions.
  • Multi-provider model harness with portable reasoning replay.
  • Access task comments, Google sign-in, and persistent light/dark themes.

0.1.0 — 2026-09-10

  • Initial open-source release: desktop app, terminal CLI, local engine, and Jolo Access.
